# Assignment_COM1321
The project contain three classes, one being ReportData.java for storing field, setter and getter 
methods, second one being Products.java for managing products that will created using blueprint class,
last one being the Main.java for running the project. This application intend to manage products for the
Extreme IT Products local supplier that specialises in the sales of the latest Information Technology hardware devices.

Everything is automated, you can add new product, search with its unique code, update, delete
the product and also print the report that contains all the products that are available along with
their quantities. This application makes the supplier's job really much easier as he will not need 
to record anything down on the paper.

The application is user friendly but it is very strict on incorrect inputs. It handles all the 
exceptions but provides only three attempts to enter the correct input, for example if you try to
enter a string instead of money for more than three times it will kick you out with a 'timeout' feedback. 
Soon as you run it all the steps on what you want to do become clear and hence it is easy to follow and 
successful perform any action of your choice.

As for the structure of the code, Product.java class does all the heavy work as it provides all the
working methods including the validating user inputs methods which are at the bottom right below the 
exitApplication() method. Comments are written to explain some parts of the code like clearing buffer 
after inputting numbers.
